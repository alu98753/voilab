## ✨ 核心優化亮點 (Highlights)

### 1. 💾 記憶體高效儲存 (Stream Batch Saving)
原始腳本會將所有錄製的回合 (Episodes) 全部在記憶體中拼接後才寫入。
- **我們的實作**：我們先計算總幀數並在 Zarr 中**預分配儲存空間 (Pre-allocation)**，隨後逐一寫入。這使得我們能在有限的記憶體下生成超大規模數據集。

### 2. 🎥 多相機系統與 MP4 自動化錄製 (Multi-Cam & Video Saving)
為了方便事後分析與模型驗證，我們增強了視角系統。
- **雙視角支援**：同步擷取腕部相機與前視角監控相機的影像。
- **自動存檔**：採集過程中，腳本會將每回合的影像自動編碼並儲存為獨立的 **MP4 影片檔**。這讓開發者無需讀取 Zarr 即可直觀檢查採集品質。
